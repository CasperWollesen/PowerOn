# PowerOn

When to power on your device 🌍

A small personal PWA that answers "when should I use power?" for Denmark's
DK1 (and DK2) price area: today's and tomorrow's prices, the cheapest hours in
your day window, what each of your appliances costs to run, an outlook for the
coming days estimated from the weather forecast, and a history of past days.

Plain HTML, CSS and JavaScript (ES modules). No build step, no backend.

Live: <https://casperwollesen.github.io/PowerOn/>

## Features

- **Today / Tomorrow** – current price with factor vs. the cheapest and most
  expensive hour, best time, cheapest 1–4 h windows, fixed-axis hourly chart.
- **Appliances** – cost per hour or per cycle now, at the best and worst time.
- **Outlook** – expected price level for the next ~7 days (very cheap … expensive)
  with drivers such as wind, sun and weekends.
- **History** – every day stored on the device, with daily averages and weather.
- **View modes** – Simple, Full and Nerd (price breakdown, statistics, hourly
  table, forecast model details). Toggle in the top bar.
- **Full price** – spot + Energinet tariffs + electricity tax + grid company
  tariff + supplier surcharge, incl. 25 % VAT. Or spot price only.
- **PWA** – installable, works offline with the last loaded data.

## Install on a phone

- **iPhone (Safari):** Share (behind the ⋯ button on iOS 26) → *Add to Home Screen*.
  iOS never shows an install prompt by itself; the app shows a hint instead.
- **Android (Chrome):** the app shows an *Install* button, or use the browser menu.

## Data sources

All are called directly from the browser (CORS-open):

| Data | Source |
|---|---|
| Spot prices, hourly | `https://www.elprisenligenu.dk/api/v1/prices/YYYY/MM-DD_DK1.json` |
| Tariffs, tax, grid companies | `https://stromligning.dk/api/Prices`, `/api/suppliers` |
| Weather (92 past + 8 coming days) | `https://api.open-meteo.com/v1/forecast` |

Energinet's Energi Data Service only allows browser requests from its own
domains, so it cannot be used directly from GitHub Pages.

Tomorrow's prices appear around 13:00; before that the price API returns 404.

## Price model

```
full price = (spot + system tariff + net tariff + electricity tax
              + grid company tariff + supplier surcharge) × 1.25
```

Tariffs are cached per day. Days without tariff data (history, outlook) use
the nearest cached day's hourly profile, or national 2026 defaults
(system 0,072 + net 0,043 + tax 0,008 kr./kWh excl. VAT).

## Outlook model

Daily ridge regression trained on up to 90 recent days:

- features: 14-day spot level, wind capacity factor in Denmark and North
  Germany, solar radiation in Denmark and Germany, temperature, weekend/holiday
- targets: spot average in the day window, cheapest 3 hours, 24 h average

A walk-forward backtest on a year of DK1 data (Sep 2025 – Sep 2026, observed
weather) gave a correlation of about 0,8 with the actual daily window average
and a mean absolute error around 0,13 kr./kWh; 67 % of days were put in the
right cheap/normal/expensive third and a cheap day was almost never predicted
as expensive. Real forecasts are less accurate further ahead, so the shown
range widens with each day. The Nerd view shows live validation numbers.

## Appliance model

```js
{ id, name, kwh, mode: 'hour' | 'cycle', durationHours }
```

## Storage

Everything lives in `localStorage` on the device: settings, appliances, about
400 days of spot prices, tariffs for ~45 days and weather. 100 days take ~110 KB.

## Local development

```bash
python dev/serve.py
```

Then open <http://127.0.0.1:8123/>. The dev server disables HTTP caching so
edited modules are picked up on reload. The API test page is at `/dev/api-test.html`.
