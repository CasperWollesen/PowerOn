# PowerOn

When to power on your device 🌍

A small personal PWA that answers "when should I use power?" for Denmark's
DK1 (and DK2) price area: today's and tomorrow's day-ahead prices, the cheapest
hours in your day window, and what each of your appliances costs to run at
different times.

Plain HTML, CSS and JavaScript (ES modules). No build step, no backend.

## Hosting

Push to GitHub and enable GitHub Pages for the `main` branch (root folder).
All paths are relative, so the app works from `https://<user>.github.io/PowerOn/`.

## Structure

```
index.html            App shell
manifest.json         PWA manifest
service-worker.js     Offline caching of the app files (bump CACHE_VERSION on releases)
css/styles.css        Styles (light/dark via CSS variables)
js/app.js             Bootstrap, state, routing, timers
js/api.js             Network access + localStorage cache of fetched days
js/prices.js          Pure price analysis (levels, periods, cheapest windows)
js/appliances.js      Appliance model, persistence and cost calculations
js/settings.js        Settings defaults, persistence, theme
js/storage.js         Defensive localStorage wrapper
js/time.js            Danish wall-clock helpers
js/format.js          Number formatting
js/chart.js           HTML/CSS bar chart with a fixed Y axis
js/dashboard.js       Dashboard view
js/settings-view.js   Settings view
icons/                App icons (PNG files generated by dev/make-icons.py)
dev/                  API feasibility test page and icon generator
```

## Data sources

- Prices: `https://www.elprisenligenu.dk/api/v1/prices/YYYY/MM-DD_DK1.json`
  (hourly spot prices in kr./kWh, excl. taxes, tariffs and VAT; tomorrow's file
  appears around 13:00, before that the API returns 404).
- Weather: Open-Meteo (reserved for a future price forecast model; not used yet).

Energinet's Energi Data Service was tested first, but it only allows browser
requests from its own domains (no `Access-Control-Allow-Origin` for other
origins), so it cannot be used directly from GitHub Pages.

## Appliance model

```js
{ id, name, kwh, mode: 'hour' | 'cycle', durationHours }
```

- `hour`: `kwh` is consumption per hour → cost/hour = kwh × price.
- `cycle`: `kwh` is consumption per cycle, spread evenly over `durationHours`;
  the app finds the cheapest start hour inside the day window (the cycle itself
  may run on past the window).

## Local development

Any static server works. With Python:

```bash
python -m http.server 8123
```

Then open <http://localhost:8123/>. The API test page is at `/dev/api-test.html`.
